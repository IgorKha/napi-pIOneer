# Проверка Adafruit — 2026-10-11

## Локально

Из корня репозитория подготовить изолированный site настоящих PyPI-библиотек:

```sh
backend/.venv/bin/python tools/adafruit-test-site.py /private/tmp/pioneer-adafruit-tests
cd backend
PIONEER_ADAFRUIT_TEST_SITE=/private/tmp/pioneer-adafruit-tests/drivers/adafruit/site .venv/bin/python -m pytest -q tests/test_circuitpython.py
```

Без site интеграционные проверки реальных wheels пропускаются; остальные тесты не требуют сети. Полный запуск на подготовленном site: 358 passed. Реальные пакеты не патчатся; проверяются численные значения BME280/SHT4x, CRC, точный framebuffer SSD1306 и частота/duty PCA9685.

## На плате

[board-bench-smoke.py](board-bench-smoke.py) устанавливает через core API четыре пакета и запускает **отдельный изолированный BenchHAL на Napi-C**. Физическая шина не затрагивается. Требуется временная авторизованная сессия в /tmp/pioneer-adafruit-session, файл mode 0600; после теста сессию отозвать и удалить файл. [Результат](board-bench.txt).

Физический LCD2004: [сценарий](../lcd-pcf8574/adafruit-smoke.py), [результат](../lcd-pcf8574/board-adafruit-2004.txt). I2C1 0x27, SDA J9-3, SCL J9-5; модуль целиком питался 3,3 В. Пользователь подтвердил все четыре ровные строки. Инициализация LCD и адаптация адресов строк 16x4 находятся в коде примера; исходные библиотеки Adafruit остаются неизменными.

## Ручной интерфейс

На отдельном локальном стенде: каталог, управление моделью BME280, создание и запуск скрипта, генерация блока, экспорт модуля. [Снимок мастера в редакторе](ui-wizard.png). На плате браузерная проверка ограничена предупреждением сертификата; деплой и аппаратный тест проверялись SSH/core API.

Проверка физических BME280/OLED и режима симуляции 006 остаётся отдельной задачей. Успех стенда не считается аппаратным доказательством.
