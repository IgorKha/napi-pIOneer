# Проверка символьных LCD с PCF8574

2026-10-11, Napi-C. Оба подключённых по очереди модуля ответили на I2C1,
адрес `0x27`. Питание всего модуля — 3,3 В; SDA — J9-3, SCL — J9-5.
Не подавать на подключённый напрямую модуль 5 В: для этого варианта нужен
двунаправленный преобразователь уровней I²C.

Скрипт `smoke.py` — самостоятельный ручной тест подключения через системный
`smbus2`, а не проверка интеграции Adafruit/Pioneer. Запускать только при
отсутствии приложения, использующего этот адрес. Другие устройства и сервисы
он не останавливает; устройство оставляет с подсветкой, RW/EN в LOW.

```sh
python3 smoke.py --rows 2
python3 smoke.py --columns 16 --rows 4
python3 smoke.py --columns 20 --rows 4
```

Распиновка переходника: P0=RS, P1=RW, P2=EN, P3=LED, P4…P7=D4…D7.
У других переходников она может отличаться. Геометрия задаётся явно:
для 16x4 адреса строк — `0x00`, `0x40`, `0x10`, `0x50`,
для 20x4 — `0x00`, `0x40`, `0x14`, `0x54`.
Последовательность четырёхбитной инициализации соответствует
[HD44780U, Figure 24](https://www.sparkfun.com/datasheets/LCD/HD44780.pdf).
Паузы увеличены: импульс EN 1 мс, пауза после байта 5 мс,
повторная синхронизация при каждом запуске. Это диагностические, а не
оптимизированные для производительности задержки.

## Результат

- LCD1602: первоначально PCF8574 принимал записи, но текст не был виден.
  После повторной инициализации с увеличенными задержками успешно прочитана
  обратно строка `Napi-C Pioneer`; пользователь подтвердил отображение.
  Причина первоначального отсутствия текста отдельно не доказана.
- Четырёхстрочный LCD первоначально был описан как 1604: чтение DDRAM
  проходило, но фото пользователя показало 20 физических колонок и смещение
  строк 3/4 в конец строк 1/2. Первоначальный лог `board-1604.txt` сохранён
  как история ошибочной настройки, а не доказательство физической геометрии.
- LCD2004: исправлены ширина и адреса строк, записаны и прочитаны обратно
  все 80 символов; сырой результат — `board-2004.txt`.
  Визуальная проверка исправленного расположения пока ожидается.

ACK переходника сам по себе не доказывает работу LCD. Этот тест проверяет
также адресный счётчик и точное содержимое DDRAM; физический контраст и
расположение строк подтверждаются отдельно. Работоспособность этих экземпляров
от 3,3 В не гарантирует её для всех LCD1602/LCD1604.
