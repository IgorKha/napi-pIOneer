## Исправлено и добавлено в этом прогоне

- Вернул «Свои блоки» в меню справки; оглавление строится по доступным руководствам.
- Добавил руководства по проектам, файлам, AI, сети, датчикам и диагностике; исправил устаревший пример публичного SDK блоков в спецификации.
- Поиск ищет все слова в содержимом и заголовках, нормализует ё/е; ссылки ведут к подразделам. Ошибка загрузки больше не оставляет вечный спиннер, доступно повторное обновление. После изменения блока обновляется справочник.
- AI-предпросмотр выделяет именно добавленные/изменённые/удалённые ноды и связи, показывает удалённые элементы и счётчики. Исходный граф остаётся неизменным до принятия.
- Три программных шаблона: импульс 10 секунд, счётчик и гистерезис. Создаются отдельными остановленными проектами без GPIO и автозапуска; плата на канвасе по умолчанию свёрнута.
- «Настройки → Система»: RAM, память core, диск, статусы, MQTT, драйверы, предупреждения и JSON-отчёт без секретов, кода, логов и cookies. Исправлено чтение Linux /proc с пустыми полями.
- SHT3x: проверка обеих CRC и восстановление после NACK. BH1750: одноразовое измерение. Ноды читают вне движка; SDK синхронный. valid/error не дают выдать старое значение за успешное новое измерение.
- Исправлены захваты I2C-адреса по умолчанию и конфликты нескольких эксклюзивных I2C/SPI/LED-нод внутри одного графа. Очистка обязательного адреса даёт неполный граф, а не падение API.
- Без WebSocket-клиентов LiveHub не опрашивает пины ради UI; источники, логи и checkpoint продолжают обслуживаться. LED опрашиваются 4 Гц вместо 20 Гц; изменение владельца обновляет их сразу.

## Закрытие оставшихся пунктов — продолжение 2026-10-11

1. **PWM и подтяжки:** реализованы sysfs HardwarePwm, SDK/граф/Bench, стабильное разрешение pwmchip через DT, диапазон 1…1000000 Гц и перестановка duty/period без EINVAL. Подтяжки — отдельный проверяемый оверлей, сохранение DHT22, конфликты/хэш/бэкап/rollback. PWM2 проверен по sysfs на 25 кГц/50% и 1 кГц/25%; после теста канал освобождён. J9-7: ядро показывает pull-up, вход читается HIGH. Осциллографом форма сигнала не измерялась.
2. **Watchdog:** явное arm/disarm в админке, проверка nowayout до открытия устройства, ioctl timeout/magic-close, heartbeat event loop + движка, штатное отключение. На плате прошли arm 60 с, один heartbeat и штатный disarm. Оставлен выключенным; намеренный reset не выполнялся.
3. **Исключено пользователем:** BME280 и физическая проверка SHT30/BH1750. DHT22 сохраняется; камера остаётся отдельной задачей.
4. **Python-модули:** ZIP и HTTPS git с фактическим commit, целые immutable версии, зависимости wheel-only вне системного Python, ноды/README для AI, worker-драйвер через общий HW, протокольные I2C/SPI-модели и изолированные JS-виджеты. Учебный регистр прошёл полный путь установки/чтения/изменения. Полная Blinka-эмуляция и каталог модулей из концепции пока не реализованы.
5. **AI:** модель отдельно для каждого запроса, до 4 текстовых/PNG/JPEG/WebP-вложений, валидация размеров/формата, маскирование известных секретов в тексте. Вложения не сохраняются в истории; внешняя передача новых изображений в этом прогоне не проверялась.
6. **Перенос/UART/редактор:** полный ZIP графа с Python-блоками, модулями и общими библиотеками; остановленная копия, конфликты и rollback. UART RX fan-out с независимыми ограниченными буферами/одним TX/одинаковым baud. Jedi: автодополнение, hover, сигнатуры, межфайловые F12/Ctrl-click, отдельный ограниченный процесс без исполнения анализируемого кода; это не отдельный LSP-сервер.

Новые тесты покрывают установку и работу протокольного модуля, архивы/коллизии, UART fan-out и частичное освобождение, порядок PWM sysfs, ограничения/форматы AI-вложений и смену модели без изменения настроек, зависимости/lock, disarmable watchdog, DT bias без захвата GPIO, таймаут зависшего симулятора. Финальная регрессия: **301 passed**, 2 предупреждения зависимостей, 36.33 с; frontend build/typecheck/Node-проверки проходят.

Ручной локальный тест: JS-виджет изменил регистр 1234 → 4567, README открыт; F12 открыл driver.py и строку определения, без ложного сообщения об отсутствии определения; AI-панель приняла тестовое текстовое вложение и отдельную модель. Использовался FakeProvider, внешнего запроса нет.
