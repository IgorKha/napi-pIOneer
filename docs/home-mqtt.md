## Тестовые топики

Граф `2401a2d9` — «Домашний MQTT: smoke (без GPIO)» — работает с автозапуском.
Он принимает команду, увеличивает счётчик, обновляет состояние и отправляет ответ
и событие. Аппаратных нод в нём нет. Префикс: `pioneer-test/napi-silverrhinoceros`.
MQTT использует топики; отдельные очереди на брокере для этого не создаются.

| Суффикс после префикса | Назначение |
|---|---|
| `cmd/smoke.echo` | Команда: `{"id":"demo-001","args":{"on":true},"ttl_ms":5000}` |
| `resp/smoke.echo` | Ответ: `{"id":"demo-001","ok":true,"result":{"on":true}}` |
| `event/smoke.changed` | Событие: `{"on":true}` |
| `state/smoke.value` | Последнее значение `on` в поле `value`, retained |
| `state/smoke.count` | Число принятых новых команд в поле `value`, retained |
| `state/smoke.link` | Состояние подключения в поле `value`, retained |
| `status` | `online` / `offline`, retained |
| `describe` | Манифест доступных команд и состояний, retained |

Подпишитесь на `pioneer-test/napi-silverrhinoceros/#`, затем отправьте JSON в
`pioneer-test/napi-silverrhinoceros/cmd/smoke.echo` с QoS 1, **без retain**.
Для новой команды используйте новый `id`; повтор того же `id` возвращает прежний
ответ без повторного увеличения счётчика. Это кэш текущего процесса: счётчик и
дедупликация сбрасываются при перезапуске сервиса. MQTT 5 `ResponseTopic` позволяет
получить ответ в собственный топик; `CorrelationData` возвращается без изменений.

Чтобы отключить стенд, остановите этот граф и выключите его автозапуск.
Остальные проекты используют то же MQTT-подключение.

## Что проверено на плате

Все девять проверок прошли: команда/ответ, событие, изменение состояний,
MQTT 5 ResponseTopic/CorrelationData, повторный id без повторного исполнения,
отклонение неверного Bool, `ttl_ms=0`, неизвестная команда, replay retained-состояний
при новой подписке. После `systemctl restart pioneer` подключение и граф
восстановились автоматически. Реальный обрыв сети и перезагрузка ОС не проверялись.

Перед деплоем сохранена копия исходных данных:
`/mount/rfs/rw/.pioneer/backups/data-before-codetree-20261011.tgz`.
Она содержит секреты и сессии, поэтому предназначена для хранения на плате,
а не для публикации. Содержимое двух прежних скриптов, двух блоков и четырёх графов
сверено с этой копией после миграции. HTTPS health отвечает `ok`, сервис активен,
в журнале после деплоя предупреждений нет; память сервиса около 54 МиБ.
