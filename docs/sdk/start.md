# Начало

pioneer превращает Napi-C в контроллер «вместо Arduino»: логика живёт на плате и работает при закрытой вкладке и после перезагрузки. Сценарии можно собирать мышкой в **проектах** (граф нод) или писать на Python в **скриптах**. Справка охватывает проекты, скрипты, свои блоки, AI, сеть, драйверы и обслуживание. Для знакомства без железа начните с [шаблонов проектов](projects.md), для кода — с примера ниже.

## Доступ

- Панель: `https://<адрес-платы>/pioneer/` (сертификат самоподписанный — браузер предупредит).
- Пароль задаётся на плате: `/mount/rfs/rw/.pioneer/bin/pioneer set-password`.
- Без платы (на ноутбуке) pioneer запускается на **виртуальном стенде**: кнопки, LED, источники напряжения добавляются на странице «Плата» → «Стенд».

## Первый скрипт: кнопка → LED

Подключите кнопку между J10-2 и 3.3 В (у J10-2 подтяжка вниз), LED с резистором 330 Ом — к J9-7. Создайте скрипт на странице «Скрипты»:

```python run
# стенд: button pin=J10-2
# стенд: led pin=J9-7
from pioneer.sdk import Input, Output, log

led = Output("J9-7")
button = Input("J10-2", debounce_ms=30)


@button.on_press
def toggle(event):
    led.toggle()
    log("LED", "вкл" if led.value else "выкл")
```

Нажмите «Запустить». Строки `# стенд:` — подсказка, что подключить на виртуальном стенде; на плате это обычные комментарии.

## Как устроен скрипт

1. Скрипт выполняется сверху вниз: создаются объекты (`Output`, `Input`…), регистрируются обработчики.
2. Если после этого есть обработчики или таймеры, **цикл событий запускается сам** — `run()` писать не нужно.
3. Цикл по очереди вызывает обработчики: фронты входов (`@button.on_press`), таймеры (`@every`, `after`).

Пины называются по гребёнке: `"J9-7"`, `"J10-2"`. Шины — по имени интерфейса: `I2C("i2c1", 0x3C)`, `UART("uart3")`, `SPI("spi2")`. Какой пин что умеет — тултип пина на странице «Плата».

## Таймеры

```python run
# стенд: led pin=J9-7
from pioneer.sdk import Output, every, after

led = Output("J9-7")


@every(0.5)
def blink():
    led.toggle()


after(3, lambda: print("прошло 3 секунды"))
```

## Не блокируйте цикл

Обработчики выполняются по одному. `sleep()` внутри обработчика останавливает **все** остальные: другие кнопки и таймеры ждут. Если обработчик работает дольше 100 мс, в лог придёт предупреждение. Вместо паузы — `after()`:

```python
@button.on_press
def pulse(event):
    relay.on()
    after(5, relay.off)   # а не sleep(5); relay.off()
```

## Остановка и ошибки

- «Остановить» завершает скрипт: выходы уходят в LOW, порты закрываются, встроенный LED возвращается системному триггеру.
- Ошибка в обработчике **не роняет скрипт**: трейсбек печатается в лог, цикл продолжает работу.
- Ошибка при создании объекта (пин занят, интерфейс выключен) завершает скрипт — текст ошибки объясняет, что делать; подробнее — раздел «Ошибки».
- Пин, захваченный скриптом, недоступен другим скриптам и проектам, пока скрипт работает. Входы (`Input`, `Adc`) — общие.

## Автозапуск

Галочка «Автозапуск» у скрипта — скрипт стартует при запуске сервиса (после перезагрузки платы примерно через 20 секунд).
