# Проекты и пульт

Проект — граф нод, который работает на плате независимо от браузера. Пульт на нодах позволяет нажимать кнопки и менять значения во время работы.

## Начните с шаблона

На странице «Проекты» выберите шаблон над списком. Создастся отдельная остановленная копия, без автозапуска и без захвата пинов.

| Шаблон | Что проверить |
| --- | --- |
| Кнопка → импульс | После запуска кнопка включает Watch на 10 секунд |
| Кнопка → счётчик | Каждое нажатие увеличивает значение |
| Температура → гистерезис | Слайдер включает выход при 35 и выключает при 30 |

Нажмите «Запустить», проверьте пульт, затем «Остановить». Для первого знакомства железо не требуется.

## Соберите свой граф

Перетащите ноды из палитры. Соедините выход с входом совместимого типа. Провод от пина платы к ноде железа назначает параметр пина; это отдельный вид соединения.

Нажмите на линию соединения: **корзинка** удаляет провод, **+** открывает поиск ноды для вставки в разрыв. Список учитывает совместимость обоих концов и показывает конкретную пару входа/выхода. Вставка создаёт ноду и заменяет один провод двумя атомарно; ⌘Z / Ctrl+Z отменяет её целиком. Для привязки пина платы доступно только удаление (снимает параметр пина). Клик по пустому канвасу скрывает действия; Escape закрывает поиск или выделение соединения.

Выберите ноду, чтобы открыть параметры в инспекторе. Неподключённые входы можно задать числом или переключателем. Ошибки подсвечиваются до запуска. Запуск остановится, если нужный ресурс занят другим проектом или скриптом.

## Группы и свои блоки

Выделите несколько нод и создайте группу для повторного использования. Свои Python-блоки редактируются в отдельном разделе [Свои блоки](blocks.md). Схема блока определяет входы, выходы и параметры, доступные в графе.

## Автозапуск и состояние

«Автозапуск» запускает проект при старте сервиса. «Сохранять состояние» отдельно сохраняет Toggle, Counter и Latch между остановками и перезапусками; для остальных нод состояние не восстанавливается. Отключение сохранения удаляет старое состояние.

Изменение параметров или связей может сбросить сохранённое состояние соответствующей ноды. Не используйте сохранение вместо проверки датчиков после запуска.

## Экспорт и импорт

Экспорт сохраняет JSON графа. Импорт создаёт новую остановленную копию с выключенным автозапуском. Пользовательские типы блоков должны быть установлены на принимающей системе отдельно. Изменения графа можно отменить; остановка освобождает ресурсы и переводит выходы в безопасное состояние.

AI предлагает изменения текущего проекта. Сначала просмотрите различия на канвасе, затем примите или отклоните предложение. Само предложение не запускает проект. Подробнее: [AI](ai.md).
