# Заметка для рабочего чата: адресация шин в SDK + задел под справку

Контекст: [004-sdk-docs.md](004-sdk-docs.md). Справку делаем в начале фазы 1, но **адресацию шин меняем сейчас**, пока скриптов мало.

## 1. Шины — по id интерфейса из `boards/napi-c.yaml`, как пины

Сейчас: `I2C(bus=1, addr=…)`, `SPI(bus=…, cs=…)`, `UART("/dev/ttyS3", baud)` — номера и пути. Станет:

```python
I2C("i2c1", 0x3C)          # интерфейс + адрес
SPI("spi2", cs=0, mode=0, speed_hz=8_000_000)
UART("uart3", baud=115200)
```

- Пользователь пишет **имя контроллера без mux-варианта** (`uart2`, `i2c3`); SDK/core резолвит в активный вариант по живому DT (`uart2_m0` или `uart2_m1` — какой включён). Точное имя с вариантом (`i2c3_m0`) тоже принимается.
- Интерфейс не включён (нет в живом DT) → `PioneerError` с понятным текстом: «uart4 выключен: нужен оверлей `rk3308-uart4` (J10-5 TX, J10-7 RX)» — данные из yaml.
- Ресурс захвата — тот же id (`i2c1@0x3C`, `spi2.cs0`, `uart3`), UI показывает пины интерфейса по yaml.
- Старые формы (`bus=1`, `"/dev/ttyS3"`) — убрать сразу (пользователей ещё нет), без deprecated-слоя.

## 2. Задел под генератор справочника (недорого сделать сразу)

- Докстринги всех публичных символов `pioneer.sdk` — в **Google-style**: краткое описание, `Args:` (с единицами/диапазонами), `Returns:`, `Raises:`, опц. `Example:` и `Hardware:` (железные предупреждения).
- `__all__` — единственный список публичного API (генератор идёт по нему).
- В `sleep()` и в цикле: замер длительности обработчика, warning в лог при > ~100 мс («обработчик блокирует цикл — используй after()»).
- `Event`: зафиксировать, что поля `pin`, `rising`, `time` стабильны; будущие `source`, `payload` (идея 003) — добавляются, не ломая.
