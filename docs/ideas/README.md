# Идеи и текущий статус

Документы ниже сохраняют исходные решения. Сверка с реализацией: [аудит 2026-10-11](../oneshot-audit.md). Статус «принято» означает согласованную идею, а не готовую функцию.

| Идея | Что готово | Что осталось |
| --- | --- | --- |
| 001 — модули и симуляция | HAL, Bench-модели, встроенные устройства, универсальные пакеты ядра | Python-манифесты периферии, установка из git/PyPI, собственные модели и виджеты |
| 002 — особенности производителя | Живой DT, конфликты пинов/портов, LED, ограничения платформы | Дополнительные RTC/w1/input/Modbus-устройства |
| 003 — remote control | HTTP/MQTT команды, состояния, ответы, origin/арбитр, дедупликация | Конкретные физические сценарии с сервой/энкодером требуют оборудования |
| 004 — справка | SDK из кода, ноды, поиск по содержимому, контекстные ссылки, проверяемые примеры | Развивать документацию вместе с каждым новым устройством |
| 005 — многофайловый код | Деревья, изоляция импортов, библиотеки, ZIP, REST/CLI | Python language server и requirements; они отложены самим решением |

Физическая камера отложена пользователем отдельно. Планы установки Python-модулей и механизм загрузки .ko в ядро — разные возможности.
