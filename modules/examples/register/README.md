# Учебный регистр I2C

Показывает полный путь установки нового Python-драйвера без изменения ядра: пакет → нода → драйвер → SDK/HAL → настоящий I2C или собственная протокольная модель.

1. Установите ZIP, подтвердив доверие к коду.
2. На Bench добавьте симулятор с bus=1, addr=72, value=1234.
3. В остановленном проекте добавьте «Регистр I2C: прочитать» и Watch. При старте Watch=1234.
4. Измените значение виджетом и подайте событие «Прочитать».

Модуль использует учебный протокол: запись номера регистра 0, затем чтение двух байт big endian. К физическому датчику этот протокол автоматически не подходит.
